# Polish (pl) glossary — TA Reborn

Conquest progression: campaign journal = dziennik; system = układ;
transport berth = miejsce transportowe; veteran berth = miejsce dla weterana;
deploy = wysłać do walki / rozmieścić; in reserve = w rezerwie.
Compatibility playback = odtwarzanie zgodności.

Player addressed as "ty" (2nd person singular, lowercase "twój/twoje"); avoid gendered past
tense for the player (wygrałeś/wygrałaś): use impersonal forms ("przetrwano"), nouns or present.
Counts: "Jednostki: {n}", "{n} × {unit}", or a noun form that suits any number.
Unit names (English, from the game data) are not declined: "jednostka {unit}", "Zbuduj: {unit}".
Quotes: „…”. Keep · × – … → % /.
