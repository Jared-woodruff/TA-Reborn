# Ukrainian (uk) glossary

Address the player with "ви" (lower case); imperatives in -іть/-те ("клацніть", "виберіть").
Vocative for the Commander: "Командире". Apostrophe: ASCII ' (font-safe). Quotes: «...».
Counts: "Noun: {n}" ("Юніти: {n}", "Знищено: {n}"); mass nouns in genitive ("{n} металу",
"{n} енергії"); minutes/seconds as "хв"/"с". Arm, Core, ARM, CORE stay in Latin (masculine
when a gendered verb cannot be avoided). Unit and map names stay in Latin (Peewee, Kbot Lab,
Luger, Mounds of Mars...). Key names stay (Ctrl, Shift, Alt, Esc, Space...).

Notes
* Order names (game.rs labels) are nouns: Атака, Бій, Патруль, Охорона, Захоплення, Посадка,
  Висадка, Воскресіння, Переробка, Рух, Ремонт; "Nothing to {order} there" is worded
  "Тут нема цілей для наказу «{order}»" so the lower-cased noun fits.
* Easy / Normal / Hard (AI level inserted in sentences) are lower case: легкий / звичайний /
  складний. Capital difficulty buttons agree with "складність": ЛЕГКА / СЕРЕДНЯ / СКЛАДНА;
  NORMAL = ЗВИЧАЙНА (also the cheats' damage option), HALF = ПОЛОВИНА, FULL = ПОВНЕ.
* Shared short keys: REPLAY = ПОВТОР (button and tag), SAVE = ЗБЕРЕГТИ (button only),
  NEXT = НАСТУПНА (mission tag and jukebox track: композиція), DONE = ГОТОВО.
* Saved games list: tag SAVED = ГРА beside ПОВТОР (the tag slot is 62 px: ЗБЕРЕЖЕННЯ does
  not fit), buttons LOAD = ГРАТИ (96 px) / WATCH = ДИВИТИСЯ.
* MEDIUM = СЕРЕДНЯ serves difficulty, galaxy size and graphics, so their labels are
  feminine: СКЛАДНІСТЬ, ГАЛАКТИКА, ЯКІСТЬ ГРАФІКИ; LARGE = ВЕЛИКА is shared with photo
  mode, whose SIZE is РОЗДІЛЬНІСТЬ. Hints quote option names: «Низька», «Повне».
* Goal phrases slot into "Знищте / Не втратьте / Доведіть {what}": accusative (свого
  Командира, ворожого Командира, всі ворожі юніти, армію ворога, будь-який свій юніт),
  genitive after the negation (всіх своїх юнітів).
* Build-menu tabs must stay short: РЕСУРСИ (ECONOMY), ЗАВОДИ, ОБОРОНА, СЕНСОРИ, ІНШЕ; the
  tutorial refers to РЕСУРСИ and ЗАВОДИ.
* Controls reference key column: ЛКМ / ПКМ / СКМ, "тягнути ЛКМ", "Двічі ЛКМ", "Коліщатко миші".

ranks (штаб-сержант, майстер-сержант, бригадний генерал...), not the abolished старшина /
прапорщик; Капрал kept from the first translation. The insignia are US-style: Brigadier has one
general's star.
